# MCP

### 란?

**MCP(Model Context Protocol)** 는 Anthropic 이 주도하는 새로운 **AI 통합 표준 프로토콜** 로, 여러 시스템이 **AI 모델과 안정적이고 일관된 방식으로 통신** 할 수 있도록 설계됨.

### 1. 핵심

* "**Context as a Service** " : AI 가 실행되기 전, 필요한 문맥(Context) 을 다양한 외부 소스로부터 가져오는 방식을 말함. MCP 는 이 컨텍스트를 어떻게 연결하고 통합할지에 대한 **표준화된 인터페이스** 임.
* **Plug & Play** 구조:  마치 USB-C 처럼, 어떤 앱이든 MCP 지원 포맷만 맞추면 AI 모델과 바로 연결 가능함.

***

## 왜 중요한가?

기존에는 AI 모델을 어떤 시스템에 연결하려면 **복잡한 커스텀 코드** 와 **데이터 전처리** 가 필요함. MCP 는 이를 크게 줄여줌.

| 기존 방식             | MCP 방식           |
| ----------------- | ---------------- |
| 시스템마다 다른 연결 방식 필요 | 공통된 프로토콜로 통합 가능  |
| 데이터 가공 코드 중복      | 표준화된 포맷으로 처리     |
| AI 모델별로 다른 통신 방식  | 공통 인터페이스로 일관성 제공 |

***

## 어떻게 구성됨?

MCP 서버는 일종의 **미들웨어 역할** 을 함. AI 모델과 다양한 외부 데이터 소스(API, DB, 파일 등) 사이에서 **컨텍스트 수집, 가공, 전달** 을 담당함.

### 기본 구성 요소

1. **MCP Router** : 외부 요청을 받아서 어디로 전달할지 결정
2. **Connector Modules** : 외부 시스템(예 : Notion, Slack, MySQL 등)과 연결
3. **Context Compiler** : 받아온 데이터를 AI 모델이 이해할 수 있도록 변환
4. **Cache Layer** : 반복 요청을 빠르게 처리
5. **Security & Auth** : OAuth2, API Key 등으로 인증 처리

***

## 개발자가 할 수 있는 일

1.  MCP 서버 구축

    대부분 Node.js, Python 기반으로 커스텀 서버를 만들 수 있음. 현재는 Anthropic 과 일부 파트너만 공식 MCP 서버를 운영하지만, 오픈소스 구현체도 조만간 나올 가능성이 큼.
2.  **MCP-Compatible 앱 만들기**

    예 : 너의 앱이 특정 유저의 캘린더에서 정보를 가져와 AI 에게 전달해야 할 경우 ⇒ MCP 포맷에 맞게 데이터를 변환하고 , MCP 서버에 POST 요청을 보내면 됨.
3.  **자체 MCP 커넥터 제작**

    특정 SaaS 서비스와 AI 를 연결하고 싶다면, MCP 커넥터를 만들어 통합 가능

***

## 사용흐름

```
[사용자 요청] → [앱] → [MCP 서버] → [Google Calendar, Notion 등에서 데이터 수집]
→ [Context Compiler로 변환] → [AI 모델에게 전달] → [응답 반환]
```
