# 사이드 프로젝트 리스트

### 1. 게임 유저 분석 플랫폼(Game User Tracker)

* 기획 : Steam API, Riot API, 또는 플레이 로그 데이터를 활용해서 유저의 플레이 패턴, 접속 시간, 랭크 변화 등을 시각화
* 포인트 :&#x20;
  * Chart.js, D3.js 등으로 그래프
  * Redis 로 캐싱, 비동기 큐로 백그라운드 크롤링 처리(Spring + RabbitMQ or Java + Kafka)
  * JWT 기반 유저 인증

***

### 2. AI + Chatbot 을 활용한 FAQ / 가이드 시스템.

* 기획 : 게임 커뮤니티나 플랫폼 FAQ 를 자동 정리하고 유저 질문에 답변해주는 봇. Langchain + Milvus or Elasticsearch 기반
* 포인트 :&#x20;
  * 사용자 질문 ⇒ 유사도 기반 검색 ⇒ 답변
  * 백오피스에서 데이터 업로드 및 관리 가능하게
  * OpenAI or Mistral API 활용

***

### 3. 멀티 게임 계정 통합 관리 툴

* 기획 : 유저가 여러 게임 계정(예 : LoL, Steam, Epic 등) 을 연동해서 관리할 수 있는 서비스
* 기능 :&#x20;
  * OAuth 연동, 계정 메모 / 태그 관리
  * 보안(2FA), 알림 기능
* 기술 포인트 :&#x20;
  * OAuth 다계정 처리
  * 사용자별 데이터 암호화(Spring Security, AES)

***

### 4. Log / Crash 분석 플랫폼

* 기획 : 로그 파일 업로드 시 에러 로그를 분석하고 비슷한 사례 추천
* 기술 :&#x20;
  * 파일 업로드 ⇒ Log Parser ⇒ 유사도 분석(Embedding)
  * 사용자별 프로젝트 관리

***

### 5. 멀티 플랫폼 게임 런처(웹 기반)

* 기획 : 웹에서 내 게임 라이브러리를 한눈에 보고 실행까지 가능하게 (Steam, Epic, GOG 통합 뷰)
* 기술 :&#x20;
  * Electron 기반 데스크탑 앱
  * OAuth / URI Scheme 연동

***

### 6. 서버 상태 모니터링 + 알림 시스템

* 기획 : 실시간 게임 서버 상태 체크(ping, 포트 상태, 응답 속도) + 관리자 알림.
* 기능 :&#x20;
  * 이슈 발생 시 Slack/Telegram 으로 확인
  * 대시보드에서 상태 변화 로그 확인
* 기술 :&#x20;
  * Node.js or Java 기반 모니터링
  * Prometheus + Grafana 연동도 옵션

***

### 7. 게임 개발사 전용 '이슈 모아보기' 플랫폼

* 기획 : 공통 이슈(로그인 장애, 패치 버그 등) 를 모아보는 내.외부 이슈 통합 플랫폼
* 기능 :&#x20;
  * 게임별 공지사항, 트위터, 유저 커뮤니티 글 스크래핑
  * 태그 기반 자동 분류("서버 다운", "핵", "오류")
* 기술 :&#x20;
  * Python + FastAPI + MongoDB
  * 프론트 : Next.js + Tailwind
