# 1:1 문의로 할 수 있는 것들

### 1. 1:1 문의 자동 분류 + 우선순위화 시스템

* **기획** : 문의 내용 ⇒ 버그 신고, 계정 문의, 욕설 신고 등 자동 태깅 + 긴급도 분류
* 기술 포인트 :&#x20;
  * HuggingFace BERT 모델로 Text Classification(혹은 OpenAI API)
  * Redis 나 Priority Queue 로 `긴급도 높은 순` 자동 정렬
  * 관리자 대시보드로 태그/우선순위 확인
* 어필 포인트
  * 자연어 처리(NLP) 실무 적용
  * 실제 CS 운영 업무 자동화 감각 어필 가능

***

### 2. 문의 응답 자동 추천 시스템

* 기획 : 비슷한 과거 문의 ⇒ 그에 대한 답변 추천 ⇒ CS 담당자는 복붙/수정만 하면 됨.
* 기술 포인트 :&#x20;
  * 과거 문의 + 답변 쌍 ⇒ 벡터화(Setence Transformers)
  * 유저 문의 입력 ⇒ 유사도 기반 검색
  * Langchain + GPT 로 답변 스타일 변환 가능
* 어필 포인트 :&#x20;
  * 벡터 DB(Weaviate, Milvus, FAISS 등)
  * AI 기반 실전 자동화 + 문서 추천

***

### 3. 문의 클러스터링 + 트렌드 분석 시스템

* 기획 : "같은 유형의 이슈가 몰릴 때" 관리자에게 알려주는 자동 이슈 감지
* 기술 포인트 :&#x20;
  * 주기적 클러스터링(KMeans or HDBSCAN)
  * 이슈 수 폭증 시 Slack/Discord 알림
  * 키워드 시각화(WordCloud or Top N Term 추출)
* 어필 포인트 :&#x20;
  * 데이터 마이닝 + Alert 시스템
  * 이슈 대응 자동화 능력 강조

***

### 4. 1:1 문의 내역 검색기(태그/키워드/상황별)

* 기획 : 운영팀/QA 가 과거 유사 이슈를 빠르게 찾기 위한 고급 검색 툴
* 기능 :&#x20;
  * 자연어 키워드로 검색
  * 날짜/태그/담당자 필터링
* 기술 :&#x20;
  * ElasticSearch + 검색 UI(React or Vue)
  * Embedding 기반 유사도 검색도 옵션

***

### 5. "답변 지연 예측기" + SLA 경고 시스템

* 기획 : 문의 도착 ⇒ 답변까지 평균 지연시간 예측 ⇒ SLA 초과 가능성 알림.
* 기술 포인트 :&#x20;
  * 과거 응답 시간 기반 회귀 분석(LightGBM or Linear Regression)
  * 특정 시간 이상 지연되면 관리자 알림.
* 어필 포인트 :&#x20;
  * 예측 모델 적용 사례
  * 실무 지표(SLA) 기반 개선 도구
