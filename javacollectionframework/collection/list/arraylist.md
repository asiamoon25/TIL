# ArrayList

## ArrayList

ArrayList 는 Java 의 **Collection Framework** 에서 가장 많이 사용되는 클래스 중 하나.

가변 크기의 배열을 제공하며, `java.util` 패키지에 포함되어 있음.

### ArrayList 특징

* **가변 크기 배열** : ArrayList는 내부적으로 배열을 사용하지만, 크기가 자동으로 조정되므로 정적인 배열보다 더 유연함.
* **순차적 데이터 저장** : 데이터가 삽입된 순서대로 저장되며, `get()` 을 통해 인덱스로 접근 가능함.
* **중복 허용** : 동일한 값을 여러 번 저장할 수 있음.
* **null 값 허용** : `null` 을 요소로 저장할 수 있음.
* **비동기** : `ArrayList` 는 동기화되지 않으므로, 멀티스레드 환경에서는 동기화 처리가 필요함. (`Collections.synchronizedList()`) 를 사용하여 동기화가 가능)

### 주요 메서드

* **추가** :&#x20;
  * `add(E e)` : 요소를 추가함.
  * `add(int index, E element)` : 지정된 인덱스에 요소를 삽입함.
* **읽기** :&#x20;
  * `get(int index)` : 지정된 인덱스의 요소를 반환함.
* **수정** :&#x20;
  * `set(int index, E element)` : 지정된 인덱스의 요소를 변경함.
* **삭제** :&#x20;
  * `remove(int index)` : 지정된 인덱스의 요소를 삭제함.
  * `remove(Object o)` : 특정 객체를 삭제함.
* **검색** :&#x20;
  * `contains(Object o)` : 해당 요소가 포함되어 있는지 확인함.
  * `indexOf(Object o)` : 지정된 객체의 첫 번째 인덱스를 반환함.
* **크기 및 초기화** :&#x20;
  * `size()`: 요소의 개수를 반환함.
  * `clear()`: 모든 요소를 제거함.
* **변환** :&#x20;
  * `toArray()` : ArrayList 를 배열로 변환함.



### ArrayList 내부 동작

* 배열 기반 구조:
  * `ArrayList` 는 내부적으로 **배열** 을 사용하여 데이터를 저장함.
  * 기본 용량은 10이며, 용량을 초과하면 현재 용량의 **1.5배로 자동 증가** 함.
* 시간 복잡도:
  * **읽기/쓰기** : 인덱스를 이용한 접근(`get()`/ `set()` ) 은 O(1)
  * **추가** : 리스트 끝에 추가하면 O(1), 중간 삽입은 O(n)
  * **삭제** : 중간 요소를 삭제하거나 배열을 재배치해야 하는 경우 O(n)



### 장점

* **빠른 읽기 및 검색** : 인덱스를 이용한 접근이 O(1) 로 빠름.
* **유연한 크기** : 동적으로 크기가 조정됨.
* **사용 편의성** : 다양한 유틸리티 메서드를 제공하여 간편하게 데이터를 다룰 수 있음.



### 단점

* **삽입 및 삭제 성능 저하** : 배열 기반이므로, 중간에 삽입하거나 삭제할 때 많은 요소를 이동해야 하므로 성능이 저하될 수 있음.
* **비동기적** : 멀티스레드 환경에서 사용하려면 추가적인 처리가 필요함.
* **메모리 낭비** : 내부 배열의 용량이 실제 크기보다 크면 사용하지 않는 공간이 생겨 메모리를 낭비할 수 있음.





### **LinkedList와의 비교**

| 특징       | ArrayList          | LinkedList         |
| -------- | ------------------ | ------------------ |
| 내부 구조    | 배열 기반              | 연결 리스트 기반          |
| 읽기 성능    | 빠름 (O(1))          | 느림 (O(n))          |
| 삽입/삭제 성능 | 중간 삽입/삭제 느림 (O(n)) | 중간 삽입/삭제 빠름 (O(1)) |
| 메모리 사용량  | 상대적으로 적음           | 상대적으로 많음           |
| 순차 접근    | 빠름                 | 빠름                 |
