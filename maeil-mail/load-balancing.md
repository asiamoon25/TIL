# Load Balancing

### 로드 밸런싱이란?

**로드 밸런싱이란 애플리케이션을 지원하는 리소스 풀에 들어오는 네트워크 트래픽(들어오는 요청)을 균등하게 분산** 하는 것을 의미함.

이를 수행하는 로드 밸런서는 애플리케이션 서버 앞단에 위치하며 클라이언트 요청을 지시하고 제어함.

이를 통해서 애플리케이션의 가용성, 확장성, 보안 및 성능을 확장할 수 있음.

***

### 알고리즘

#### 1. 라운드 로빈(Round Robin)

라운드 로빈 방식은 모든 요청이 순서대로 처리되는 방식임. 서버 3대(A, B, C) 가 존재하면 요청은 ABCABC 순서대로 전달됨.

모든 서버의 처리 능력이 동등하고 ,요청의 고른 분산이 중요한 경우 고려해볼 수 있음.

구현이 쉬우며 고른 분산을 보장한다는 것이 장점임. 하지만, 서버 부하나 응답시간을 고려하지 않고 서버의 처리 능력이 다른 경우 비효율적이라는 것이 단점임.

#### 2. 가중치 라운드 로빈

라운드 로빈 방식에 가중치라는 개념을 추가함. 각 서버는 처리 능력과 가용 자원에 따라서 가중치를 할당 받게 됨. 그리고 ,라운드 로빈 방식을 사용하되 가중치가 높은 서버는 가중치에 비례하여 상대적으로 더 많은 요청을 받게됨.
